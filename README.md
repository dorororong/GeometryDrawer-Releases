# Geometry Drawer

조건을 입력하면 자와 컴퍼스 작도 순서를 찾고, 점을 움직여도 조건이 지켜지는지 확인한 도형을 그려 주는 Windows 프로그램입니다.

- 다운로드·안내: https://dorororong.github.io/GeometryDrawer-Releases/
- 최신 exe: [GeometryDrawer.exe](https://github.com/dorororong/GeometryDrawer-Releases/releases/latest/download/GeometryDrawer.exe)

이 저장소에는 배포 파일과 안내 페이지만 있습니다. 새 버전은 Releases에 올라가며,
프로그램의 '업데이트 하기'는 개발자 서명이 확인된 버전만 설치합니다.
