Geometry Drawer
작동 방식 사용 설명서 설치 자주 묻는 질문

조건만 적으면,
작도 순서까지 맞는 도형을

“AB = 5, ∠C = 90°” 같은 조건을 입력하면 자와 컴퍼스로 그리는 순서를 찾고, 점을 움직여도 조건이 지켜지는지 확인한 도형을 그려 줍니다. 시험지·학습지용 그림을 Windows에서 바로 만듭니다.

Windows용 다운로드
Windows 10·11 (64비트) · 설치 없이 실행

처음이라면 사용 설명서를 따라 해 보세요. 화면을 보며 순서대로 따라 할 수 있습니다.

작동 방식

그림을 “그럴듯하게” 맞추는 대신, 조건에서 출발해 작도하고 검증합니다.

입력조건을 직접 쓰거나, 문제 그림·문장을 AI로 변환
조건 확인변환된 조건(IR)을 보고 고칠 수 있음
추론·초안숨은 사실을 찾고 조건을 만족하는 배치를 계산
작도자와 컴퍼스로 그리는 순서를 구성
인증점을 움직여 보며 조건이 계속 지켜지는지 확인

할 수 있는 것

작도판은 기본 브라우저에서 열립니다. 별도 브라우저나 Python 설치는 필요 없습니다.

직접 조건 입력

블록이나 한 줄짜리 조건으로 입력합니다. API 키나 인터넷 없이 쓸 수 있습니다.

그림·문장 변환 (선택)

문제 사진이나 문장을 조건으로 바꾸고, 사진의 문제 글을 수식째 한글로 옮깁니다. OpenAI·Claude·Google·Upstage 가운데 쓰는 회사의 본인 API 키가 필요하고 사용료가 듭니다.

시험지용 마무리

글꼴·선 굵기 조절, 변 방향 고정, PNG 내보내기, 그림 복사, 문장 편집, 도면 저장·열기.

한글 수식 복사

문장과 수식을 한컴 한글의 수식 개체로 복사합니다. 한글이 설치된 PC에서 동작합니다.

내 PC에만 저장

도면·설정·API 키는 내 컴퓨터에만 남고, 키는 비밀번호로 암호화합니다. AI 변환을 쓸 때만 그 사진·문장이 고른 AI 회사로 전송됩니다.

버튼 한 번으로 업데이트

실행 창의 ‘업데이트 하기’가 새 버전을 받아 확인한 뒤 교체하고 다시 실행합니다.

설치와 실행

설치 과정이 없는 단일 실행 파일입니다.

  1. 1
    다운로드

    위의 버튼으로 GeometryDrawer.exe를 받아 원하는 폴더(예: 바탕화면, 문서)에 둡니다. 업데이트를 위해 쓰기 가능한 폴더가 좋습니다.

  2. 2
    실행

    더블클릭하면 작은 실행 창이 뜨고 기본 브라우저에 작도판이 열립니다. 첫 실행은 몇 초 걸릴 수 있습니다.

  3. 3
    종료

    실행 창을 닫으면 프로그램이 끝납니다. 그 전에 작업을 저장하세요.

“Windows의 PC 보호” 창이 뜨면 아직 코드 서명 인증서가 없어 처음 실행할 때 나타날 수 있습니다. 추가 정보 → 실행을 누르세요. 받은 파일이 이 페이지에 적힌 SHA-256과 같은지 확인하려면 PowerShell에서 Get-FileHash GeometryDrawer.exe를 실행해 비교하면 됩니다.

안전과 개인정보

무엇이 어디에 저장되고, 업데이트가 어떻게 확인되는지.

저장 위치

%LOCALAPPDATA%\GeometryDrawer에 저장합니다. exe를 옮기거나 업데이트해도 그대로 남습니다.

  • 저장한 도면은 비밀번호로 암호화
  • API 키는 exe에 들어 있지 않고, 입력한 키도 암호화해 보관
  • AI 변환(사진·문장 → 조건)을 쓰면 그 사진과 문장이 고른 AI 회사(OpenAI·Anthropic·Google·Upstage)로 전송됩니다. 각 회사의 데이터 처리 방침이 적용됩니다. 직접 조건 입력과 작도는 전송 없이 이 PC에서만 동작합니다.
  • AI 변환에 넣은 사진·문장 기록은 30일이 지나면 자동으로 지웁니다
  • 작도판은 이 PC 안에서만 열리는 주소(127.0.0.1)로 동작하고, 다른 웹사이트는 접근할 수 없음

업데이트 확인

새 버전 정보에는 개발자의 서명이 붙어 있습니다. 프로그램은 서명과 파일 해시가 모두 맞을 때만 교체하고, 새 버전이 시작되지 않으면 이전 버전으로 되돌립니다. 저장한 도면·비밀번호·API 키는 유지됩니다.

자주 묻는 질문

기능별 자세한 사용법은 사용 설명서에 화면과 함께 있습니다.

인터넷이 꼭 필요한가요?

직접 조건을 입력해 작도하는 기능은 인터넷 없이 됩니다. 그림·문장 AI 변환과 업데이트 확인에만 인터넷이 필요합니다.

AI 변환은 어떻게 켜나요?

작도판의 ‘로그인’에서 비밀번호를 정한 뒤 ‘API 키’에 쓰려는 회사(OpenAI·Claude·Google·Upstage)의 본인 키를 입력하고, 문제 입력의 ‘AI’ 목록에서 모델을 고릅니다. 비밀번호는 8자 이상이며 저장되지 않으니 잊지 않도록 해 주세요. 잊으면 암호화된 도면과 키를 열 수 없습니다.

작도가 끝나지 않으면?

한 도형당 30초가 지나면 자동으로 멈춥니다. 조건이 너무 많거나 서로 맞지 않는 경우가 많으니, 조건을 확인하거나 줄여서 다시 시도하세요.

문제가 생기면 어디를 보나요?

실행 창의 ‘저장 폴더’를 누르면 열리는 폴더의 logs에 실행 기록이 있습니다. 8765 포트가 사용 중이면 다른 포트를 자동으로 고릅니다.

이전 버전을 쓰고 있어요 (1.0.13 이하)

이전 버전은 업데이트 위치가 달라서 버튼으로 새 버전을 받지 못합니다. 이 페이지에서 한 번만 새로 받아 기존 파일을 바꿔 주세요. 그 뒤로는 ‘업데이트 하기’로 받을 수 있습니다.
